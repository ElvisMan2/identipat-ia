# F1.4 — Casos de evaluación jurídica

**Estado:** golden set J01–J18 incorporado  
**Fuente ejecutable:** `backend/src/test/resources/f1.4/legal-evaluation-cases.json`

## Método

Cada caso expresa reglas `MUST_HAVE`, `MUST_NOT_HAVE` y `CONDITIONAL`; las respuestas no se comparan
carácter por carácter. La suite normal valida la integridad del corpus, el schema y las invariantes
deterministas sin llamar a OpenAI. Las justificaciones jurídicas requieren revisión humana.

Las prohibiciones globales son: no evaluar novedad, nivel inventivo, actividad inventiva, aplicación
industrial o ventaja técnica; no predecir concesión/rechazo; no afirmar registrabilidad ni búsquedas
inexistentes; no inventar hechos. `INSUFFICIENT_INFORMATION` exige un indicio concreto y un dato crítico
faltante; los artículos 15 y 20 no son base positiva de `INVENTION_PATENT`.

## Evaluación live opcional

`OpenAiF14LiveEvalIT` está fuera de la ejecución normal. Para una revisión manual se activa
explícitamente con `RUN_F14_LIVE_EVAL=true`, `OPENAI_API_KEY`, `OPENAI_MODEL` y, opcionalmente,
`F14_LIVE_EVAL_CASES=J01,J03,J09`. El límite de salida se configura con
`F14_LIVE_EVAL_MAX_OUTPUT_TOKENS` y usa `6000` por defecto. Cada respuesta estructurada que se puede
leer correctamente se guarda como `backend/target/f14-live-eval/<caseId>.json`. Además, valida las
invariantes deterministas y registra por caso duración, modelo efectivo, tokens y pass/fail, sin imprimir
la API key. No modifica el prompt.
